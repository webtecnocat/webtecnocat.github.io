Instal·lació de fonts

josepm · 20 de setembre de 2019
Aquest contingut ve de les primeres versions de Tecnocat, d'abans del 2019. Algunes instruccions, enllaços o versions de programes poden haver quedat desfasats.

Algun cop ens ha calgut tipus de fonts que no tenim instal·lades a l’ordinador, per tenir-les disponibles tenim diferents maneres.

Per instal·lar les fonts tenim tres maneres diferents, anem a veure cada cas:
1.- Instal·lar les fonts tant sols per un usuari.
2.- Instal·lar les fonts per tots els usuaris.
3.- Instal·lar les fonts des del repositori.

1.- Instal·lar les fonts tant sols per un usuari.

Fem doble clic a sobre del fitxer de la font, i li donem instal·lar.

2.- Instal·lar les fonts per tots els usuaris.

Perquè la font estigui disponible per tots els usuaris, cal que estigui instal·lada a la carpeta /usr/share/fonts, per l’usuari administrador.

Tot seguit recarreguem la memòria de les fonts amb la comanda:

sudo fc-cache -f -v

3.- Instal·lar les fonts des del repositori.

Es fa la instal·lació des del synaptic com si fos un altra programa. Podem trobar les fonts dels repositoris amb la paraula fonts, ttf, otf, …

Per una informació més detallada: Pràctica 11 de http://tecnocat.eu/?q=node/28
