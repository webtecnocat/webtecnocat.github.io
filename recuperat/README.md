# Material recuperat de l'Internet Archive

Contingut de les webs antigues de tecnocat.eu (Drupal, 2014-2016) que no era a la còpia de WordPress. Es va descarregar de web.archive.org l'octubre de 2026.

- `imatges/`: imatges que faltaven a la còpia de WordPress (de tecnocat.eu/sites/default/files/), i les de les dues pàgines recuperades.
- `pagines.json`: les pàgines "Bateries de Liti-Ió: Consells d'utilització" i "Linux" (altres.tecnocat.eu/?q=node/7 i node/8).

`eines/construeix.py` ho afegeix a la web quan la genera.
